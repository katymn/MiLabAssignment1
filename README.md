# 🌕 Moon Base VR Scene

Welcome to **Moon Base VR**, an interactive virtual reality experience built with **Unity** and **C#**, designed for the **Oculus/Meta Quest** headset. Explore a futuristic lunar base where two quirky astronauts — Barry & Larry — bring the moon to life with dance, chickens, and discovery.

---

## 🚀 Project Overview

This project experiments with immersive VR mechanics and environmental storytelling. The scene features:
- A sci-fi **moon base terrain** with dynamic **lighting**, **fog**, and atmosphere
- Two astronauts:  
  - **Barry**, who dances to music  
  - **Larry**, who raises chickens  
- Interactive **teleportation** via blue orbs to explore the base  
- Physics-based objects you can **grab, rotate, and scale**  
- Audio effects, text labels, and outline highlighting to enhance engagement

---

## 🎮 Features

- VR integration with Oculus Quest  
- Terrain creation and environmental effects (fog, lighting)  
- Teleportation system via clickable orbs  
- Character animations synced with audio  
- Interactive objects with physics (gravity, manipulation)  
- Outline effect to indicate interactable items  
- On-screen text for UI and feedback

## 🧩 Installation & Setup Instructions

2. **Open the project in Unity:**  
   Ensure Unity Editor is installed with Universal Render Pipeline (URP) support.

3. **Import the Oculus Integration package:**  
   In Unity, go to **Window > Asset Store** or the Unity Asset Store website, search for **Oculus Integration**, and import it into your project.

4. **Set up XR Plugin Management:**  
   Go to **Edit > Project Settings > XR Plugin Management** and enable **Oculus** for your target platform.

5. **Connect your Oculus Quest headset:**  
   - Enable developer mode on your device.  
   - Plug it into your PC via USB or use Oculus Air Link.

6. **Play the scene:**  
   - Open the main scene
   - Press **Play** in the Unity Editor to test VR interactions.

7. **Build and deploy (optional):**  
   - Go to **File > Build Settings**  
   - Select **Android** platform (Quest runs on Android)  
   - Build and run on your Oculus device.

> ⚠️ **Note:** Some files or configurations may be a bit janky or require tweaks due to switching laptops during development. Thanks for your patience!
